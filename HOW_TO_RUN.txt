    - Test data       : Benchmark family s35932 (held out)

Option 2 (Whole-Dataset Stratified Split):
    python src/train_gnn.py \
        --split-strategy stratified \
        --train-ratio 0.70 \
        --val-ratio 0.15 \
        --test-ratio 0.15 \
        --checkpoint checkpoints/trojan_gnn_whole_dataset.pt

    - Pools all 338 netlists across all 4 circuit families.
    - Stratifies across families: 70% train (236 netlists), 15% val (51), 15% test (51).
    - Guarantees zero graph leakage (each circuit is an independent graph).

6. GNN + STRUCTURAL EVIDENCE + LLM PIPELINE (EXPERIMENT C)
--------------------------------------------------------------------------------
Command:
    python src/run_experiments.py --experiment C --circuit data/TRIT-TS/s13207_T421/s13207_T421.v
or:
    python src/pipeline.py data/TRIT-TS/s13207_T421/s13207_T421.v

Details:
    - GNN scores netlist and extracts suspicious seeds (score >= 0.95).
    - Expands 2-hop structural region around seeds (max 50 nodes).
    - Extracts topological evidence, boundary exits, and local structural patterns.
    - Anonymizes identifiers with zero benchmark/Trojan leakage.
    - Queries LLM (Gemini or local Qwen) for structural explanation and verdict.
    - Outputs:
        results/evidence/s13207_T421_evidence.json
        results/anonymized/s13207_T421_evidence_anonymized.json
        results/llm/s13207_T421_prompt.txt
        results/llm/s13207_T421_gemini_llm.json
